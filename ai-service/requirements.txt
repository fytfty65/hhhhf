# AI service runtime dependencies.
#
# Every entry is pinned to the version the code is developed and tested against.
# Four packages the code actually imports (numpy, networkx, scikit-learn, redis)
# were previously missing entirely, so `pip install -r requirements.txt` on a
# clean machine produced a service that failed at `import agent`. The floating
# `>=` bounds also meant two CI runs a week apart could install different code.
#
# Bump deliberately, then re-run `python -m unittest discover -s tests` and the
# planner smoke test.

# ddgs is the *preferred* DuckDuckGo client: core/web_price_tool.py:1459 tries
# `from ddgs import DDGS` first and only falls back to the legacy package below.
# That legacy package is abandoned — the code's own comment at
# core/web_price_tool.py:1451 records it returning 0 results — so omitting ddgs
# meant a clean `pip install -r requirements.txt` (exactly what CI does) silently
# degraded web price search to a dead backend while every test still passed.
# Both are pinned: ddgs is the working path, duckduckgo-search remains only as the
# fallback for environments that still have it.
